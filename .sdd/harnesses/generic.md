# generic

Manual Superpowers setup: copy each folder under `skills/` in https://github.com/obra/superpowers to .agents/skills/<skill-name>/SKILL.md in this repository, preserving the skill's name and contents. Configure this harness to load .agents/skills, restart it, then invoke the brainstorming skill to confirm discovery. Open a fresh session per role and load .sdd/roles/<role>.md explicitly.

Model assignment: guidance. Verify model availability in the harness.
