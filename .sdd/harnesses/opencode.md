# opencode

Manual Superpowers setup: edit `~/.config/opencode/opencode.json`; for OpenCode V1 add `"superpowers@git+https://github.com/obra/superpowers.git"` to the `plugin` array, and for V2 add it to the `plugins` array. The plugin registers its skills with OpenCode. Restart OpenCode, use its native skill tool to list and load `brainstorming` to confirm it loads, and restart after bootstrap/update to reload project agents and skills. Full instructions: https://raw.githubusercontent.com/obra/superpowers/refs/heads/main/.opencode/INSTALL.md.

Model assignment: native-config. Verify model availability in the harness.
